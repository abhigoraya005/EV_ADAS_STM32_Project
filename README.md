# EV ADAS STM32 Project 🚗

Embedded Systems based EV ADAS project using STM32 Blue Pill, STM32CubeIDE, and PICSimLab.

## Completed Modules

### Day 1 — LED Blink

* STM32 GPIO basics
* LED control

### Day 2 — ADC Sensor Inputs

* Analog sensor reading
* UART monitoring
* Potentiometer interfacing

### Day 3 — Ultrasonic Sensor

* HC-SR04 integration
* Distance measurement
* Microsecond timer control

### Day 4 — Collision Warning System

* Distance based WARNING/DANGER alerts
* Real-time UART monitoring

### Day 5 — Multi Sensor ADAS

* Front obstacle detection
* Left obstacle detection
* Right obstacle detection
* Multi-sensor real-time monitoring

## Hardware Used

* STM32 Blue Pill (STM32F103C8T6)
* HC-SR04 Ultrasonic Sensor
* Potentiometers
* UART Virtual Terminal

## Software Used

* STM32CubeIDE
* PICSimLab
* VS Code
